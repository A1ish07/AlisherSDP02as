## ~A.Alisher

## Project Purpose
Java console application demonstrating Factory Method (for logistics transport) and Abstract Factory (for UI components).  
Supports combinations of delivery mode road/sea and UI platform windows/macos.

## Structure
- `factorymethod` – Transport interface, Truck, Ship, Logistics, RoadLogistics, SeaLogistics  
- `abstractfactory` – (Button, Checkbox, GUIFactory) interface , WindowsFactory, WindowsCheckbox, WindowsButton, MacOSFactory, MacOSCheckbox, MacOSButton 
- `app` – DeliveryApplication client and Main startup class

## Prerequisites
- JDK 17  
- Any Java IDE (IntelliJ IDEA recommended)
